# Coin Rich

Coin Rich is a cryptocurrency trading dashboard for watching markets, tracking holdings, and reviewing trading context in one place.

After signing in, you land on a dashboard with market statistics, sentiment, a Fear & Greed reading, and a live price chart. The market page lists top coins, global cap and volume, and trending names. The portfolio page lets you add, update, and remove holdings, then shows value, cost basis, profit and loss, and allocation.

There is also a screener for venture-capital-style wallets and sample firm holdings, a chat panel for market and portfolio questions, and an NFT page that previews a coming gallery. A public landing page introduces the product before login.

## Installation

Requires Node.js 18 or later.

```sh
git clone <GIT_URL>
cd <REPO_NAME>
npm install
```

Start the app:

```sh
npm run dev
```

This starts: http://localhost:3000
